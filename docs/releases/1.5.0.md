# Killa YuE 1.5.0 — Studio expansion

Create, shape and finish music on your phone, free and open source.

- **Mixer and effects**: groups, sends, editable effect chains, EQ, compressor, limiter, delay, reverb, saturation and filter.
- **Automation**: editable curves for levels, pan, sends and effect parameters, with undo and saved projects.
- **Mastering**: Dynamic, Balanced and Loud presets, measured loudness and sample peaks, and Before/Mastered comparison.
- **Instruments**: piano-roll editing, a two-row keyboard, and original Killa Pluck and Killa Tines sounds streamed from storage.
- **The Chamber**: four pattern banks, song order, note repeat, sixteen velocity levels, mute/solo, and one Undo step for a pad-recording pass.
- **Killa Gold pads**: gold frames, dark rubber faces and amber pressed artwork.
- **Unfinished songs**: listen to a checkpoint without changing it, save the preview separately, and resume the original; preview progress reports elapsed time.
- **Updates**: check GitHub for a new version, review its notes, download and verify the APK, and confirm installation through Android.

## Install

Download killa-yue-1.5.0.apk and install it over your existing app. Songs, projects and models stay in place. Android 9+, arm64; other devices remain untested beyond the Galaxy S25 Ultra.

Studio projects use format 9. Keep a backup before opening a project in an older app version.

## Validation and remaining coverage

The combined Studio/preview build passed the S25 Ultra device checks: 151 native assertions, a ten-minute audio stress run with zero device xruns, and UI checks for editing, exports, undo/redo, instruments and Chamber recording. The combined release sources passed 880 counted Java regression assertions and the Android API 37 compile check. The updater was separately verified by the maintainer.

Headphone and external audio-route listening, USB/Bluetooth MIDI playback, and other phones still need community validation. Loudness limiting measures sample peaks, not true peaks. The release does not add MIDI recording or acoustic instrument recordings.
