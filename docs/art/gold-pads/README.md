# Killa Gold Chamber pads

Generated in the shared Pixella Firefox editor on ops, 2026-10-17, with its **GPT Image 2.5**, **Square**, **1K** settings, as requested in ASTRA_PROMPT_STUDIO2.md. The exported PNG dimensions are recorded in the testing note. The full-resolution exports are kept on ops under `~/showcase/killa-yue-art/` and copied unchanged into `app/assets/skins/gold/`.

- `padGold.one`: original resting-pad prompt, used in Create.
- `padGoldLit.one`: original struck-pad prompt supplied by Claudia.
- `padGoldLit.edit.one`: actual Edit prompt, adding alignment instructions to the supplied struck prompt. The reference is our generated `padGold.png`.

The first Edit attempt inherited a stale wide-button reference in Pixella. That result was rejected. The square resting PNG was explicitly uploaded before the accepted Edit attempt.

No text, logo or sampled third-party artwork was added to these assets. `GoldPadArt` shares the two decoded bitmaps, preserves the square aspect ratio and changes only the built-in `gold` skin. Touch uses pressed state; MIDI note-on pulses for 120 ms. Selection remains the existing foreground outline. Playback of saved patterns does not animate the artwork.
